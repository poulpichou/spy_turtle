# Other Ideas

## Next Development Blocks
### Frontend
- Make the central area switchable between the camera, logs and photo gallery.
- Use more of the available vertical space.
- Remove the **Send** button and send messages with **Enter**.
- Slightly enlarge the text input area.
- Reduce dropdown sizes on smartphones.

### Hardware
- Configure servo center positions, minima, maxima and movement ranges.
- Complete servo wiring.
- Prepare LED classes and modes while waiting for remaining hardware.
- Keep motor work paused until the hardware is available.

### Behaviors
- Study a true low-power idle mode while keeping the robot reachable.
- Add a touch-control mode on the shell display.
- Wake that mode when the screen is touched.
- Expand eye expressions, especially **dizzy** and a pencil-drawn mode.

### Exploratory Features
- Face tracking with the head.
- Following a person like a pet.
- Local recognition of known people.
- Voice chatbot.
- Live audio relay.
- Voice recording and playback, optionally with voice transformation.
- Sentry mode with alerts.
- A small coordinated dance.

## Suggested Order
Start with the frontend because its first improvements form a coherent and immediately testable block. Afterwards, perform a structured feasibility review of the AI-related features before implementing them.
